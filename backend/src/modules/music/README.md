# Music Module (`modules/music`)

## Purpose
Exposes an ambient audio catalog (Lo-fi, Rain, Brown Noise, Fantasy, Cafe, Nature) served from CDN/config for Gate focus and study sessions per §6.16 (FR-MUSIC-001).

## Endpoints
- `GET /api/v1/music/catalog`: Category breakdown and full catalog.
- `GET /api/v1/music/tracks`: Filterable track list.
