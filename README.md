# Arise Life OS

This repository is organized into three separate standalone projects:

## 📁 Repository Structure

- `client_web/` - React + Vite + Tailwind CSS web application
- `client_flutter/` - Flutter cross-platform mobile & web application
- `server/` - Node.js / TypeScript backend server

---

## 🚀 Running the Apps

### 1. Web Client (React)
```bash
cd client_web
npm install
npm run dev
```

### 2. Flutter Mobile/Web Client
```bash
cd client_flutter
flutter pub get
flutter run
```

### 3. Backend Server
```bash
cd server
npm install
npm run start
```
